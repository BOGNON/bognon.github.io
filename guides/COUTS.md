# Coûts : ce qui est gratuit et ce qui ne l'est pas

| Poste | Coût | Remarque |
| --- | --- | --- |
| Hébergement GitHub Pages | Gratuit | Dépôt public, compte GitHub gratuit, sans carte bancaire. Limites : 1 Go de site, environ 100 Go de trafic par mois. |
| Lien HTTPS `https://bognon.github.io/` | Gratuit | Certificat fourni par GitHub. |
| Nom de domaine personnalisé (`bognonisaac.com`…) | **Payant**, chaque année | Prix variable selon l'extension et le registraire. Facultatif. |
| Polices, icônes, images du site | Gratuit | Polices sous licence libre SIL OFL, hébergées avec le site. |
| Formulaires de contact et de devis | Gratuit | Ouvrent l'e-mail ou WhatsApp : aucun service tiers, aucune base de données. |
| Google Search Console, Bing Webmaster Tools | Gratuit | Compte Google ou Microsoft nécessaire. |
| Outils de test (Playwright, axe-core, Lighthouse, html-validate) | Gratuit | Logiciels libres installés par `npm install`, uniquement sur votre ordinateur. |
| Node.js, Git, Visual Studio Code | Gratuit | Pour modifier et republier le site. |
| Développement avec Claude | Selon votre forfait Claude | Ce travail utilise le quota d'utilisation de votre compte ; il n'est pas compris dans l'hébergement. Les limites dépendent de votre abonnement. |
| Connexion Internet, téléphone | À votre charge | Pour publier et pour recevoir les demandes. |
| Paiement en ligne | Non inclus | Volontairement absent de la version 1. L'ajouter plus tard impliquerait un prestataire de paiement (frais par transaction) et probablement un autre hébergement. |

Aucun abonnement n'est nécessaire pour que le site reste en ligne.
